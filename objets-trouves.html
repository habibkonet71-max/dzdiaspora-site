🔍 Objets Trouves

Vous avez trouve un objet ? Deposez une fiche. Vous avez perdu quelque chose ? Recherchez par code secret. Systeme securise — le contact ne s affiche que si vous connaissez le code.

🔐 Comment fonctionne le code secret ?
Choisissez un mot ou code que SEUL le proprietaire de l objet peut connaitre (ex: couleur interieure du sac, prenom grave, autocollant...). Le proprietaire devra taper exactement ce code pour voir vos coordonnees.
✅ Votre fiche a ete enregistree avec succes ! Merci de votre geste.

Ce code ne sera JAMAIS affiche publiquement. Seul quelqu un qui le connait verra vos coordonnees.
